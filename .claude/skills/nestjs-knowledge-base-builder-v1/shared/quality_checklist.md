# 质量要求清单 (验证子skill引用)

> 所有12+1个文档生成完毕后，验证子skill使用本清单逐项检查。

---

## 15条质量要求

1. **零遗漏**: 每个 NestJS Module 中的 Controller/Service 都必须在某个文档中有记录
2. **代码支撑**: 每个结论必须标注来源文件和行号
3. **路由精准**: `03_路由与控制器.md` 中的路由必须写实际路径（如 `/api/users/:id`），禁止只写 Controller 名
4. **数值精准**: 所有装饰器参数、守卫配置、限流参数必须解析到实际数值
5. **版本精准**: NestJS 版本和相关库版本必须精确到 minor
6. **依赖完整**: 模块依赖图必须包含所有 imports 和 exports
7. **DTO完整**: 所有请求体验证规则（class-validator 装饰器）必须列出
8. **Entity完整**: 所有实体字段类型、关系装饰器（@OneToMany 等）必须列出
9. **安全覆盖**: 认证/授权守卫、角色装饰器、公开接口必须在文档中清晰标注
10. **无逻辑矛盾**: 同一数据在不同文档中描述必须一致
11. **API完整**: 所有 @Get/@Post/@Put/@Patch/@Delete 路由都被记录
12. **配置完整**: 所有环境变量、自定义配置项必须列出
13. **数据流清晰**: 从请求到响应的完整链路可追踪
14. **新人人友好**: `09_项目结构总览.md` 不假设读者了解项目背景
15. **来源可追溯**: 每个文档中的每个事实都能对应到源码位置
