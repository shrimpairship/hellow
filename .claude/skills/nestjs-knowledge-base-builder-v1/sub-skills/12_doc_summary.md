# 子Skill 12: 生成 SUMMARY.md

> **职责**: 综合所有已生成的知识库文档，生成一页纸项目总结。
> **输入**: 已生成的全部知识库文档（00-11）
> **输出**: `SUMMARY.md`

---

## 必须遵守的共享规则

开始前先读取:
- `shared/iron_rules.md` — 铁律规则
- `shared/format_spec.md` — 排版规范

---

## 执行前：判断运行模式

### 数据读取规则
本子skill的数据来源主要是已生成的知识库文档（非 `_analysis/`）：
- `01_项目介绍.md` → 项目名称、一句话描述、核心功能
- `02_模块架构.md` → 模块架构图
- `09_项目结构总览.md` → 架构图
- `06_API接口文档.md` → API 概览
- `08_配置与环境.md` → 技术栈信息
