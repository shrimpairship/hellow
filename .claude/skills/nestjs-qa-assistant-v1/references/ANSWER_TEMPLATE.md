# 回答模板

> 根据不同的问题类型，使用对应的回答模板。

---

## 细节优先问题模板

```markdown
**答案**：[直接给出具体值]

**证据来源**：
- `{文件名}:{行号}` — {具体有什么}

**说明**：[如果适用，给出上下文说明]

**确认建议**：[如果需要人工确认，给出建议]
```

### 示例

**问题**：JWT 过期时间是多少？

**答案**：JWT 访问令牌过期时间为 3600 秒（1 小时），刷新令牌过期时间为 7 天。

**证据来源**：
- `src/config/jwt.config.ts:10` — `expiresIn: 3600`
- `src/config/jwt.config.ts:12` — `refreshExpiresIn: '7d'`

## 概念优先问题模板

```markdown
**答案**：[直接结论，1-2句话]

**工作流程**：
1. [步骤1] — `{文件:行号}`
2. [步骤2] — `{文件:行号}`
3. [步骤3] — `{文件:行号}`

**架构图**：[如果有，用 Mermaid]

**关键代码位置**：
- `{文件名}:{行号}` — {说明}

**设计原因**：[解释为什么这么设计]
```

### 示例

**问题**：用户注册流程是怎样的？

**答案**：用户注册是一个 4 步流程：请求验证 → 邮箱查重 → 密码加密 → 用户创建。

**工作流程**：
1. `AuthController.register()` 接收 `CreateUserDto`，经过 `ValidationPipe` 验证
2. `AuthService.register()` 检查邮箱是否已存在
3. 密码通过 `bcrypt.hash()` 加密（`src/auth/auth.service.ts:35`）
4. `UserRepository.save()` 持久化用户数据（`src/auth/auth.service.ts:38`）

**关键代码位置**：
- `src/auth/auth.controller.ts:15-28` — 注册路由入口
- `src/auth/auth.service.ts:30-48` — 注册业务逻辑
