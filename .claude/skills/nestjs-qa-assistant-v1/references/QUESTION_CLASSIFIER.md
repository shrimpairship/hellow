# 问题分类器

> 用于确定用户问题属于哪一类，以选择正确的检索路由。

---

## 问题分类方法

### 关键词匹配法

| 问题类型 | 触发关键词 |
|---------|-----------|
| detail-first | 多少、几、什么值、默认、配置、端口、版本、限制、超时、阈值 |
| concept-first | 如何、怎么样、为什么、流程、架构、关系、设计、原理、区别 |
| debug | 报错、为什么出错、怎么调试、排查、定位、解决 |
| newcomer | 怎么上手、从哪开始、目录结构、快速入门 |

### 语义判断法

**Detail-First（细节优先）**：
- 用户问的是一个具体的、可量化的值
- 答案通常是一个数字、字符串、布尔值
- 例如："JWT 过期时间是多少？"、"数据库端口是什么？"

**Concept-First（概念优先）**：
- 用户问的是某个东西是怎么工作的
- 答案通常需要步骤说明、流程图、架构图
- 例如："用户注册流程是怎样的？"、"模块之间如何依赖？"

**Debug（排错）**：
- 用户遇到了错误或异常
- 答案通常是排查步骤、常见原因
- 例如："为什么 401 错误？"、"数据库连接失败怎么办？"
